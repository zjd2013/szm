# SZM · 首字母造句工坊

输入两个长度为 **2 或 3** 的字符串（支持**中文汉字词语/姓名**或**英文字母缩写**），自动提取并拼合两个字符串的拼音首字母（支持 **正序 `A + B`** 与 **交换顺序 `B + A`**），生成符合现代汉语 **`（主）谓（宾）` + 可选语气词** 语法结构的趣味短语。

## 核心特性

- **双输入兼容**：同时支持输入 2–3 个中文汉字（自动上下文识别多音词，如「音乐 → yy」「快乐 → kl」，并支持手动切换多音字读音）或直接输入 2–3 位字母首字母（含 `i/u/v` 智能谐音映射提示）。
- **正逆序双向拼合**：自动探索 `init(A) + init(B)` 与 `init(B) + init(A)` 两种顺序，逐字标注首字母归属来源（A / B 双色徽标）与完整声调拼音。
- **严整（主）谓（宾）+ 语气词语法引擎**：
  - 支持 `主+谓+宾`、`主+谓+宾+语气词`、`语气词+主+谓+宾`、`主+谓(+语气词)`、`谓+宾(+语气词)` 等多种合法句式。
  - 内置细粒度语义选择限制（人物、动物、固体食物、饮品、自然风物、器物、文本、场所、抽象概念），避免生硬乱拼。
  - 支持按拼接顺序、语法句式、短语风格（日常自然 / 文艺浪漫 / 沙雕整活）筛选及「换一批」轮换。

## 本地运行与测试

```bash
npm install
npm run dev    # 启动开发服务器
npm test       # 运行词库完整性与随机首字母组合 100% 覆盖测试
npm run build  # TypeScript 类型检查与生产构建
```
