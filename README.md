# SZM · 首字母造句工坊

输入任意两个字符串（不限 2–3 字，单字、姓名、词语、成语、短句或首字母缩写均可，每串支持 **1–12** 字），自动提取并拼合两个字符串的拼音首字母（支持 **正序 `A + B`** 与 **交换顺序 `B + A`**），基于 **CP-generator v2（74,523 词 · 604,878 组搭配 · 746,252 条语料原句）× 影视字幕依存统计（40,941 词 · 196,673 组搭配）** 的双语料合并概率引擎，生成地道流畅、符合 **`［主语］+［状语］+ 谓语 +［宾语］+［语气词］`** 结构的中文短语与短句。

## 核心特性

- **CP-generator v2 双语料引擎（74,523 词 · 604,878 组搭配 · 746,252 条原句）**：
  - 完整移植 [CP-generator](https://csna350akioi.github.io/CP-generator/) 的生成引擎（`src/engine/cpEngineLib.js`，原项目未附 LICENSE，保留原作者实现与注释、仅改写导出尾部）与全部数据（`public/cp-corpus.bin`：约 880 万条字幕 / 日常聊天 / 菜谱 / 餐厅点评 / 问答短句）；惰性加载、完全离线。
  - 依存链概率 + **语料原句命中**双通道评级：整句在 880 万短句中出现过即直接判「地道」，卡片展示「原句命中 N 次」徽标；`P(dep|head)` 按精确搭配 + 细/中/粗三级语义簇插值回退，通用词（不/很/是/有）降权，整句可信度取各链乘积。
  - **三重反例门控**：边界歧义再切分（`吃|好玩|家` → 降级）、谓–名粘连（`快乐|人|生` → 降级）、语气词搭配度统计（`终于…了` 常见 vs `终于…吗` 罕见；`什么/谁/怎么` 禁 `吗`；`哇` 仅接 `u/ao` 韵母）。
  - **共享流畅度守卫**（`src/engine/fluencyGuards.ts`）：CP 的原句命中只认共现频次，会放过「我蛮喜欢谁」这类句子，与 SZM 禁句清单取并集后置过滤，双引擎同标准把关。
  - **分层合并策略**：两引擎结果先按评级分层（地道 > 通顺 > 勉强 > 硬凑），层内各自头部轮流进前排、按整句去重；CP 负责短句原句质感，SZM 负责多分句长串、吉言呼应与 `o/e` 生僻声母兜底。
- **升级版大规模依存语料词库（40,941 词 · 196,673 组搭配 · 95 组状语）**：
  - 借鉴 [CP-generator](https://csna350akioi.github.io/CP-generator/) 基于大规模真实对白依存句法统计的 `P(主)·P(谓|主)·P(宾|谓)` 插值平滑模型（精确搭配 + 细语义簇 + 粗语义簇 + 基础词频回退）与四级真实度评级（**地道 / 通顺 / 勉强 / 硬凑**）。
  - **词库深度升级与缺陷修复**：
    1. 清洗原始字幕中的低俗脏词与高频西方翻译人名干扰，修复 `月亮 / 玫瑰 / 巧克力 / 汉堡 / 小狗` 等大量普通中文名词的误标专名降权问题，打通 `快乐 / 幸福 / 烧烤 / 樱花 / 考拉` 等兼类词的宾语与主语角色；
    2. 大规模增补原语料缺失的现代高频茶饮美食（`奶茶、牛奶、炸鸡、螺蛳粉、草莓、糖葫芦` 等）、职场校园与亲友称谓（`闺蜜、室友、学霸、打工人` 等）、浪漫风物（`晚霞、星河、夏天、未来` 等）及缺失核心动词（`等、给、开、回、抢、逛、点、喂、撸、旅游、拍照、微笑` 等）；
    3. 升级支持 **64 个单字状语 + 31 个双字口语状语**（`不想、不要、一起、偷偷、已经、终于、快来、打算` 等）与双字复合语气词（`了吗、了吧、好吗、对吧` 等）；
    4. 补齐全部 **23 个汉语拼音声母**（含 `e / o` 等生僻声母）单字兜底，消除空结果死角。
- **姓氏多音字智能识别 & 无 2–3 字限制**：
  - 自动识别人名首字常见多音姓氏（如 `单→s`、`曾→z`、`解→x`、`仇→q`、`区→o`、`查→z`、`朴→p`），同时保护普通双字词不被误判，支持一键切换多音字读音。
  - 突破 2–3 字限制：2–7 字生成一气呵成的单句，8 字及以上自动支持匀称连贯的多分句复句。

## 本地运行与测试

```bash
npm install
npm run dev          # 启动开发服务器
npm test             # 运行语料词库规模、多音姓氏与全长度 100% 覆盖测试
npm run build        # TypeScript 类型检查与生产构建
npm run build:pages  # 生成 GitHub Pages 静态部署产物至 /docs
```
