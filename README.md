# SZM · 首字母造句工坊

输入任意两个字符串（不限 2–3 字，单字、词语、成语、短句或首字母缩写均可，每串支持 **1–12** 字），自动提取并拼合两个字符串的拼音首字母（支持 **正序 `A + B`** 与 **交换顺序 `B + A`**），生成自然流畅、贴近现代口语且符合 **`（主）谓（宾）` + 可选语气词** 语法结构的中文短语与短句。

## 核心特性

- **无 2–3 字限制，全长度自适应**：
  - 支持单字、双字、三字、四字成语乃至更长短句输入（自动忽略空格），同时兼容中文汉字（支持多音词识别与手动切换读音）与英文字母首字母（含 `i/u/v` 智能谐音映射）。
  - 2–7 字优先生成一气呵成的单句；8 字及以上自动支持对仗匀称的连贯复句（如「哥想发财，万事如意」）。
- **口语通顺度与母语搭配引擎**：
  - 内置现代高频口语助动/状语结构（如 `想买`、`不想上班`、`快来追`、`下班摸鱼`）、数量名短语（如 `一杯奶茶`、`一只小猫`）及双字自然语气词（`其实`、`原来`、`好吗`、`对吧`）。
  - 引入母语级动宾/主谓惯用搭配加分表，区分心理动词与动作动词的程度副词修饰边界，大幅降低生僻古字权重，告别生硬拼字。
- **正逆序双向拼合与语法可视化**：自动探索 `init(A) + init(B)` 与 `init(B) + init(A)` 两种顺序，逐字标注首字母来源（A / B 双色徽标）、完整声调拼音与主谓宾成分。

## 本地运行与测试

```bash
npm install
npm run dev          # 启动开发服务器
npm test             # 运行词库完整性与全长度随机首字母组合 100% 覆盖测试
npm run build        # TypeScript 类型检查与生产构建
npm run build:pages  # 生成 GitHub Pages 静态部署产物至 /docs
```
